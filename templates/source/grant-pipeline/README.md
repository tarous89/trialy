# Grant Pipeline 1.0.1 — app 9

An applicant-side grant tracker for small commercial biotech research teams. It covers opportunities, mandatory eligibility evidence, human decisions, applications, milestones and per-currency funding review. It does not apply to funders, receive cash, or confer eligibility automatically.

Canonical inputs are `source.js`, `style.css`, `catalog.metadata.json`, `schema.example.json` and `demo_data.json`. `preview.html` and `../../apps/life.grant-pipeline-1.0.1.json` are generated by `node scripts/build-grant-template.mjs`; `--check` fails on drift and runs in the repository build. The catalog loader discovers the JSON automatically. Do not edit generated files or overwrite a released template version.

All mandatory setup and automation instructions, including the complete scalar schemas, are embedded in catalog metadata returned through MCP. `HOST_INTEGRATION.md` explains installation and revision, `AUTOMATION_RECIPES.md` explains optional work, and `QA.md` records validation and its limits. The supplied ZIP is input provenance, not the production registration format.

Open `preview.html` for the same renderer with clearly fictional, in-memory data. Its review dialog and layout prompt are demonstrations. Use the production-host browser test to verify actual connected controls and native layout persistence. No demo rows are installed into customer tables.

The app remains usable with zero automations. All six screens inherit app-level access; hidden screens/fields are presentation choices, never security boundaries. Reads are bounded to 200 records per role. Incomplete authorized data suppresses totals/eligibility and blocks dependency-sensitive writes; use a complete smaller authorized dataset for larger workspaces.
