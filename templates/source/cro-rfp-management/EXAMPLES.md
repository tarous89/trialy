# User-to-result examples

1. **"We received a Phase II oncology RFP from Alpine Bio. We need a CRO bid by November 18."** ChatGPT prepares one authorized RFP intake with scope, sponsor, owner, due date and source reference; no generated fake sponsor account or automatic invitation. Bid/no-bid needs rationale, reviewer and date.
2. **"Take the sponsor RFP questions and split them by scientific, operations, data, QA, legal and commercial."** ChatGPT only processes explicitly provided/authorized text; writes candidate requirement rows with original source section and responsible SME via reviewed proposals. Uncertain or unparseable items stay flagged.
3. **"Reuse our approved monitoring answer for this specific question."** Choose a non-expired library source/version; prepare an update to the selected question as **Drafted**, with source reference and cleared reviewer/date. Do not edit the canonical library source.
4. **"Show me what stops this proposal from being submitted."** Check complete authorized data: mandatory approved questions, required dated reviewer evidence, a Finance gate, approved proposal revision/source references; report exact gaps without inventing scores.
5. **"Our QA reviewer has approved the quality section."** A dated owner/evidence record is required for review gate approval; an unchecked button never bypasses backend review. The status alone cannot assert release readiness.
6. **"Prepare a proposal with ChatGPT and email it to the sponsor."** The app can prepare an evidence-linked **draft** for user review. It **must not** send the proposal externally; the CRO records submission manually after authorization and release gate checks. Internal TrialAgents status email is separate and optional.
7. **"Please move Proposal Review before Response Library and show Sponsor before RFP in the intake table."** Open native Settings → Layout via gear, drag stable keys with host keyboard/touch support, review expected version; preserve underlying data and permission scope. Standalone HTML preview cannot claim persisted layout.
8. **"Please remind me about upcoming RFP deadlines every week."** Offer reviewed post-save shared ChatGPT weekly check or a simple TrialAgents internal scheduled reminder using supported typed action fields; no new per-app Task, no sponsor recipients from contact fields.
