# Regulatory Radar 1.0.0 (`life.regulatory-radar`)

Watches regulators for one or more scopes: guidances, designations, advisory committees, decisions, policy changes and open consultations, one row per agency, title and date, with the programs each one affects. Built on the [Bio Radars kit](../../radar-kit/README.md) 1.1.0; scope: [BIO_RADAR.md](../../../../docs/product/app-template-blueprints/apps/BIO_RADAR.md) §2, §3 and §5. **Draft:** not in `templates/catalog-seed.json` until the owner approves it.

| File | Purpose |
|---|---|
| `radar.json` | The definition: scope fields (agencies, topics, indications, designation_types), tracker fields, natural key (agency, title and date), event kinds (guidance, designation, adcom, regulatory_decision, policy, consultation_open), digest section ("New guidances and designations"), standard sources (FDA, EMA, MHRA, National agencies, Official journals), default research instruction, monthly cadence (first Monday, 07:00), Coming up window (180 days). Generated by `../_tools/make_wave3.py`. |
| `catalog.metadata.json` | Description, tags, whenToUse, whenNotToUse. |
| `demo_data.json` | Fictional scope, regulatory items, events and runs. |
| `schema.example.json`, `regulatory-radar.preview.html` | Generated by `scripts/build-radar-templates.mjs`. |
| `QA.md` | §5 results. |

Roles: `organizations` (core.v1), `programs` (core.v1, optional, read-only), `regulatoryradar.settings`, `.scopes`, `.items`, `.events` (output, `radar.v1`, one writer), `.runs`.

Automations (install dialog, both selected): **Regulatory Radar scan + digest** (monthly) and **Regulatory Radar high-impact alert**, as for every radar. Research may create and update regulatory items (except watched, seen_run_id, dismissed, user_notes, archived), create events and create runs; it never touches scopes or the template.
