# Funding Radar 1.0.0 (`life.funding-radar`)

Watches financings, IPOs and grants for one or more scopes, one row per company, kind and date, with amounts as announced and lead investors. The digest lists rounds in your space with a period total per currency. Built on the [Bio Radars kit](../../radar-kit/README.md) 1.1.0; scope: [BIO_RADAR.md](../../../../docs/product/app-template-blueprints/apps/BIO_RADAR.md) §2, §3 and §5. **Published:** approved by the owner on 15 November 2026; `templates/catalog-seed.json` approves it on first import (migration 074).

| File | Purpose |
|---|---|
| `radar.json` | The definition: scope fields (modalities, indications, regions, stages, round_kinds), tracker fields, natural key (company, kind and date), event kinds (financing, ipo, grant), digest section ("Rounds in your space"), standard sources (Press releases, News, SEC filings, EU Funding & Tenders, NIH RePORTER), default research instruction, weekly cadence (07:00). Generated by `../_tools/make_wave2.py`. |
| `catalog.metadata.json` | Description, tags, whenToUse, whenNotToUse. |
| `demo_data.json` | Fictional scopes, financings, events and runs. |
| `schema.example.json`, `funding-radar.preview.html` | Generated by `scripts/build-radar-templates.mjs`. |
| `QA.md` | §5 results. |

Roles: `organizations` (core.v1), `programs` (core.v1, optional, read-only), `fundingradar.settings`, `.scopes`, `.financings` (output, `radar.v1`, one writer), `.events` (output, `radar.v1`, one writer), `.runs`. The Financings table is also published as a `radar.v1` output (`fundingradar.financings`, one writer), so Fundraise or a dashboard can read it.

Automations (install dialog, both selected): **Funding Radar scan + digest** and **Funding Radar high-impact alert**, as for every radar. Research may create and update financings (except watched, seen_run_id, dismissed, user_notes, archived), create events and create runs; it never touches scopes or the template.
