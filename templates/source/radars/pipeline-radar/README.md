# Pipeline Radar 1.0.0 (`life.pipeline-radar`)

Watches competitor pipelines for one or more scopes: new entrants, phase changes, partnerships, discontinuations and readouts, one row per company and asset. Built on the [Bio Radars kit](../../radar-kit/README.md) 1.1.0; scope: [BIO_RADAR.md](../../../../docs/product/app-template-blueprints/apps/BIO_RADAR.md) §2, §3 and §5. **Draft:** not in `templates/catalog-seed.json` until the owner approves it.

| File | Purpose |
|---|---|
| `radar.json` | The definition: scope fields (indication, mechanism, modality, line, geographies), tracker fields, natural key (company and asset), event kinds (new_entrant, phase_change, partnership, discontinuation, readout, other), digest section ("Phase changes and new entrants"), standard sources (Company pipelines and press releases, Public pipeline summaries, News), default research instruction, weekly cadence (07:00). Generated by `../_tools/make_wave2.py`. |
| `catalog.metadata.json` | Description, tags, whenToUse, whenNotToUse. |
| `demo_data.json` | Fictional scopes, assets, events and runs. |
| `schema.example.json`, `pipeline-radar.preview.html` | Generated by `scripts/build-radar-templates.mjs`. |
| `QA.md` | §5 results. |

Roles: `organizations` (core.v1), `programs` (core.v1, optional, read-only), `pipelineradar.settings`, `.scopes`, `.assets`, `.events` (output, `radar.v1`, one writer), `.runs`. 

Automations (install dialog, both selected): **Pipeline Radar scan + digest** and **Pipeline Radar high-impact alert**, as for every radar. Research may create and update assets (except watched, seen_run_id, dismissed, user_notes, archived), create events and create runs; it never touches scopes or the template.
