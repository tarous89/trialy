# Patent Radar 1.0.0 (`life.patent-radar`)

Watches patents for one or more scopes: publications, grants, legal events, oppositions and expiries in the next 24 months, one row per patent family, including your own families. Every screen and email says **Not legal advice**. Built on the [Bio Radars kit](../../radar-kit/README.md) 1.1.0; scope: [BIO_RADAR.md](../../../../docs/product/app-template-blueprints/apps/BIO_RADAR.md) §2, §3 and §5. **Draft:** not in `templates/catalog-seed.json` until the owner approves it.

| File | Purpose |
|---|---|
| `radar.json` | The definition: scope fields (targets, cpc, assignees, own_families, offices), tracker fields, natural key (family ID), event kinds (patent_published, patent_granted, legal_event, opposition, expiry_upcoming), digest section ("New grants and legal events"), standard sources (Espacenet, Google Patents, Lens.org, USPTO, EPO Register), default research instruction, monthly cadence (first Monday, 07:00), disclaimer, Coming up window (730 days). Generated by `../_tools/make_wave3.py`. |
| `catalog.metadata.json` | Description, tags, whenToUse, whenNotToUse. |
| `demo_data.json` | Fictional scope, patent families, events and runs. |
| `schema.example.json`, `patent-radar.preview.html` | Generated by `scripts/build-radar-templates.mjs`. |
| `QA.md` | §5 results. |

Roles: `organizations` (core.v1), `programs` (core.v1, optional, read-only), `patentradar.settings`, `.scopes`, `.families`, `.events` (output, `radar.v1`, one writer), `.runs`.

Automations (install dialog, both selected): **Patent Radar scan + digest** (monthly) and **Patent Radar high-impact alert**, as for every radar. Research may create and update patent families (except watched, seen_run_id, dismissed, user_notes, archived), create events and create runs; it never touches scopes or the template.
