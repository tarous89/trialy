# Trial Radar 1.0.0 (`life.trial-radar`)

Watches clinical trials for one or more scopes: registrations and changes (status, dates, enrollment, endpoints), readouts, results postings and stopped trials. Built on the [Bio Radars kit](../../radar-kit/README.md); scope: [BIO_RADAR.md](../../../../docs/product/app-template-blueprints/apps/BIO_RADAR.md) §2, §3 (Trial row) and §5. **Published:** approved by the owner on 15 November 2026; `templates/catalog-seed.json` approves 1.0.0 on first import.

| File | Purpose |
|---|---|
| `radar.json` | The definition: scope fields (indication, interventions, sponsors, phases, countries), tracker fields, natural key (registry ID: EU CT number, else NCT ID), event kinds, digest section, standard sources (TrialAgents Intel (EU CTIS) first, then ClinicalTrials.gov, WHO ICTRP, company releases), default research instruction, weekly cadence (Monday 07:00). |
| `catalog.metadata.json` | Description, tags, whenToUse, whenNotToUse. |
| `demo_data.json` | Fictional: 2 scopes, 12 trials, 14 events, 3 runs (WHO ICTRP not reachable in all 3). |
| `schema.example.json`, `trial-radar.preview.html` | Generated by `scripts/build-radar-templates.mjs`. |
| `QA.md` | §5 results. |

Roles: `organizations` (core.v1), `programs` (core.v1, optional, read-only), `trialradar.settings`, `.scopes`, `.trials`, `.events` (output, `radar.v1`, one writer; readers leave dismissed rows out), `.runs`.

Automations (install dialog, both selected): **Trial Radar scan + digest** (weekly research on the chosen runner that updates trials, events and runs, then the digest written by `digest_summary`) and **Trial Radar high-impact alert** (after the scan; `alert_summary` sends one email only for high-impact events on watched trials). Research may create and update trials (except watched, seen_run_id, dismissed, user_notes, archived), create events and create runs; it never touches scopes or the template.
