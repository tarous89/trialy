# Deal Radar 1.0.0 (`life.deal-radar`)

Watches licensing, collaboration and M&A deals for one or more scopes, one row per parties, kind and date. Only publicly disclosed amounts are recorded; the digest lists the largest disclosed deals and a period total per currency (currencies are never added together). Built on the [Bio Radars kit](../../radar-kit/README.md) 1.1.0; scope: [BIO_RADAR.md](../../../../docs/product/app-template-blueprints/apps/BIO_RADAR.md) §2, §3 and §5. **Draft:** not in `templates/catalog-seed.json` until the owner approves it.

| File | Purpose |
|---|---|
| `radar.json` | The definition: scope fields (modalities, indications, regions, deal_kinds, stages), tracker fields, natural key (parties, kind and date), event kinds (deal_announced, deal_terminated, option_exercised), digest section ("Largest disclosed deals"), standard sources (Press releases, SEC filings, News), default research instruction, weekly cadence (07:00). Generated by `../_tools/make_wave2.py`. |
| `catalog.metadata.json` | Description, tags, whenToUse, whenNotToUse. |
| `demo_data.json` | Fictional scopes, deals, events and runs. |
| `schema.example.json`, `deal-radar.preview.html` | Generated by `scripts/build-radar-templates.mjs`. |
| `QA.md` | §5 results. |

Roles: `organizations` (core.v1), `programs` (core.v1, optional, read-only), `dealradar.settings`, `.scopes`, `.deals` (output, `radar.v1`, one writer), `.events` (output, `radar.v1`, one writer), `.runs`. The Deals table is also published as a `radar.v1` output (`dealradar.deals`, one writer), so Partnerships or a dashboard can read it.

Automations (install dialog, both selected): **Deal Radar scan + digest** and **Deal Radar high-impact alert**, as for every radar. Research may create and update deals (except watched, seen_run_id, dismissed, user_notes, archived), create events and create runs; it never touches scopes or the template.
