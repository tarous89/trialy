# Data contract

Eight roles with explicit saved real database type IDs and logical-to-snake_case physical fieldMap. All fields scalar, multiple:false. People (name, professional_id, specialty, title, country, status, priority, interest, source_url, verified_at, opt_out, notes, archived); institutions (name, city, country, kind, source_url, verified_at, archived); affiliations (name, person_id, institution_id, role, start_at, end_at, source_url, verified_at, archived); experience (name, person_id, institution_id, registry_id, trial_role, specialty, source_url, verified_at, archived); engagements (name, person_id, institution_id, project_ref, channel, occurred_at, owner, purpose, outcome, next_step, notes, archived); collaborations (name, person_id, institution_id, project_ref, status, invited_at, responded_at, owner, notes, archived); actions (name, person_id, engagement_id, owner, due_at, status, completed_at, detail, archived); findings (name, person_id, source_url, source_type, topic, verified_at, reviewer, reviewed_at, status, rationale, archived). Date fields typed date; archived and opt_out boolean; enum choices embedded in instructions. URLs and notes use text, UUID references scalar text. Required fields: people name/specialty/status/source_url/verified_at; institutions name/country/source_url/verified_at; affiliations name/person_id/institution_id/role/start_at/source_url/verified_at; experience name/person_id/registry_id/trial_role/source_url/verified_at; engagements name/person_id/channel/occurred_at/owner/purpose/outcome; collaborations name/person_id/project_ref/status/owner; actions name/person_id/owner/due_at/status; findings name/source_url/source_type/topic/verified_at/status. Optional identifiers null, no arrays, no patient records. Source URLs https, verified date must be recorded; duplicate affiliation person+institution+start, experience person+registry+role, professional ID unique when known; name-only duplicate not inferred. Map every field including optional relationships, archived and optOut; missing access is unknown. All archived and optOut values must be explicit booleans (initialize false only on a genuinely new record; never infer false for an existing unknown preference). Empty optional dates, references and selects use null, text may be empty. Arrays/objects are invalid. Reads cap at 960 rows per role and 96 calls overall. Independent Database edits require reconciliation; these are app guards, not database foreign keys.

The accompanying schema_mapping.example.json supplies exact create_type definitions and logicalFields. Every column has multiple:false. Use committed parent receipt UUIDs for child references. No example IDs or rows belong in production.
