# Optional automation

When sponsor clinical operations needs recurring, consented professional-source verification or deadline-based team notifications. Manual use remains fully functional without it.

After saving, read read_app_automation_guide, read_automation_setup, list_app_automations and read_app_automation. Reuse the shared owner/workspace runner and existing objective; stable authoringKey co04-investigator-public-source-update. Suggested Monday 09:00 in the owner-confirmed IANA timezone, approved anchor and expiry, 7-day initial lookback, coalesced catch-up, bounded 20 profiles/run. Use current app-bound read fields/inheritAppAccess:true, check optOut and approved source scope at execution. No per-app ChatGPT Task. Respect paused/disconnected setup; prefer supported Work chat, high reasoning and latest most capable available model, reporting actual host settings separately. Never invent host IDs or model parameters.

Use public CTIS/trial registry, institution and publication metadata only. Match professional identifier plus affiliation; dedupe by identity, URL and evidence date. Return exact URLs, verification dates, ambiguity and source gaps. One-time drafts stay in the authorized conversation; recurring drafts stay in private permission-checked monitoring results/history. No reports table and no automatic database writes. A user can separately review Candidate findings using real optional person UUIDs. No winner, availability or consent inference. Complete scope with zero findings is completed; no_update only with complete coverage and an approved quiet policy. Partial/blocked/expired/revoked work does not advance coverage. Preserve receipts/checkpoints on retries. Optional email is a separate single-step TrialAgents action when actions.status enters Open, rechecking archived is not true; fixed subject Investigator follow-up recorded, fixed body Open https://platform.trialagents.com to review your authorized investigator follow-up. Only the registered owner and specifically selected currently authorized teammates; never investigator/contact addresses. No research completion email or second schedule. Delivery failure does not rerun research. No job/email is activated by template metadata; manual use works without setup. Preserve IDs, disabled state, hidden configuration and grants on edits; outcomes belong in Logs.

Weekly, if expressly approved: inspect the existing authorized investigator profile and affiliation records, query public CTIS/trial registry/institution/publication sources for updated professional evidence in EU/UK oncology/neurology/rare diseases, de-duplicate by professional identifier and institution, and propose candidate evidence with source URLs and verified dates. Preserve original evidence and report partial coverage, no auto-contact. No task should be configured unless user opts in.

The typed automation.example.json is also embedded in the catalog quickStart. Replace all placeholders, choose authorized registered recipient users and confirm the exact action only when requested. No real job or email is created by this package. No automatic database writes are included in the weekly read-only research objective. Partial source results do not advance coverage.
