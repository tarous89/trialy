## Suite and specifications

The [23-app blueprint collection](app-template-blueprints/README.md) records the life-science design briefs. Corresponding versioned packages are in `templates/apps/` with source documentation in `templates/source/`. The database catalog's approval status, not a blueprint or packaged example, determines user visibility. Installation creates empty tables; demo records remain previews.

The original 18-use-case research and 11-function showcase plan are [historical](../archive/README.md). They do not define current navigation or prohibit custom apps. A blueprint's proposed screen list is not proof that every proposed behavior shipped.
